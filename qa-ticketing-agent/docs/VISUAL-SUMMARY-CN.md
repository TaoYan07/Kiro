## 🧠 向量搜索原理

```
┌─────────────────────────────────────────────────────────────────────┐
│                      向量搜索工作原理                                │
└─────────────────────────────────────────────────────────────────────┘

步骤1: 文本 → 向量
─────────────────────────────────────────────────────────────────────

  "如何重置密码"
        │
        │  OpenAI Embeddings API
        │  model: text-embedding-3-small
        │
        ▼
  [0.12, 0.34, 0.56, 0.78, ..., 0.91]
  └────────────────┬────────────────┘
                   │
              1536维向量


步骤2: 计算相似度
─────────────────────────────────────────────────────────────────────

  查询向量: Q = [0.12, 0.34, 0.56, ...]
  文档向量: D = [0.15, 0.32, 0.58, ...]

  余弦相似度公式:
  
         Q · D
  cos = ─────────
        ||Q|| ||D||

  其中:
  • Q · D = 点积 (dot product)
  • ||Q|| = Q的模 (magnitude)
  • ||D|| = D的模

  计算结果: 0.95 (非常相似)


步骤3: 排序和返回
─────────────────────────────────────────────────────────────────────

  所有文档的相似度分数:
  
  Doc1: 0.95 ⭐⭐⭐⭐⭐
  Doc2: 0.88 ⭐⭐⭐⭐
  Doc3: 0.65 ⭐⭐⭐
  Doc4: 0.42 ⭐⭐
  Doc5: 0.15 ⭐

  返回 Top 3:
  [Doc1, Doc2, Doc3]


可视化表示:
─────────────────────────────────────────────────────────────────────

  向量空间中的相似度:

         Doc1 (0.95)
            ↗
  Query ──→ Doc2 (0.88)
            ↘
         Doc3 (0.65)

  角度越小 = 相似度越高
  Doc1与Query的角度最小，所以最相似
```

时间线示例:
─────────────────────────────────────────────────────────────────────

T0: 创建工单
    TICKET-003: "用户无法登录"
    status: open
    priority: high

    status: open → in_progress
    assignee: dev-team
    comment: "正在调查数据库连接"

T2: 更新进度 (+30分钟)
    comment: "发现是连接池配置问题"
    priority: high (保持)

T3: 问题解决 (+2小时)
    status: in_progress → resolved
    comment: "已修复连接池配置并部署"

T4: 确认关闭 (+1天)
    status: resolved → closed
    comment: "用户确认问题已解决"

## 🎯 决策树

```
┌─────────────────────────────────────────────────────────────────────┐
│                    是否创建工单决策树                                │
└─────────────────────────────────────────────────────────────────────┘

                        用户提问
                           │
                           ▼
                    ┌──────────────┐
                    │  搜索知识库   │
                    └──────┬───────┘
                           │
                ┌──────────┴──────────┐
                │                     │
                ▼                     ▼
         找到结果？              没有结果
         results > 0             results = 0
                │                     │
                │                     │
                ▼                     ▼
         ┌──────────────┐      ┌──────────────┐
         │ 生成答案      │      │ 生成答案      │
         │ confidence: ? │      │ confidence: 低│
         └──────┬───────┘      └──────┬───────┘
                │                     │
                │                     │
                ▼                     ▼
         置信度 >= 0.7?          ┌──────────────┐
                │                │  创建工单 ✓  │
        ┌───────┴───────┐        │ priority:    │
        │               │        │ - issue→high │
        ▼               ▼        │ - other→med  │
      YES              NO        └──────────────┘
        │               │
        │               │
        ▼               ▼
  ┌──────────┐   ┌──────────────┐
  │ 返回答案  │   │  创建工单 ✓  │
  │ (无工单)  │   │ + 返回答案   │
  └──────────┘   └──────────────┘


决策规则:
─────────────────────────────────────────────────────────────────────

创建工单的条件（满足任一）:
  ✓ 知识库无结果 (results = 0)
  ✓ 答案置信度低 (confidence < 0.7)
  ✓ 用户明确报告问题 (intent = "issue")

不创建工单的条件:
  ✓ 知识库有结果 AND
  ✓ 答案置信度高 (confidence >= 0.7)

优先级设置:
  • intent = "issue" → priority = "high"
  • intent = "question" → priority = "medium"
  • intent = "request" → priority = "medium"
```
